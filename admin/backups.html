Backups

A backup is one encrypted file with the website's content: events, sermons, ministries, leaders, messages, prayer requests, the newsletter list and settings. Admin accounts are never included.

Keep a copy on your own device

Backups saved on the server are lost if the server itself is lost or replaced. After making a backup, download it and keep it somewhere safe that is not the server, such as a computer or an external drive. Keep its passphrase in a password manager, apart from the file.
