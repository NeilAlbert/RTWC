Backups

The Backups page makes a copy of the website's content in one file: events, sermons, ministries, leaders, messages, prayer requests, the newsletter list and settings. You can choose to include the uploaded photos too. Admin accounts and passwords are never in a backup.

Each backup is locked with a passphrase that you choose when you make it. Nobody can open the file without it, and it cannot be recovered or reset, so keep it in a password manager.

Backups are kept on the server until you delete them. The server can be lost too, so download each backup and keep it on a computer or an external drive. Deleting a backup on the page does not touch a copy you have downloaded.

The automatic monthly backup, once switched on, makes a backup on the 1st of each month by itself. It keeps the number of automatic backups you choose and deletes older ones. It uses a passphrase that is set on the server, so ask whoever looks after the server to keep a copy of it.

To restore, choose a backup file (or Restore on a saved backup), enter its passphrase, and check the summary. Restoring replaces the website's content with the backup's. It needs your admin password and the word RESTORE typed in, and it makes a safety backup of the current data first, listed as "Before restore". Admin accounts are never changed, and images already on the website are never overwritten.
